# Order Management System (C++)

A console-based order management system inspired by e-commerce platforms like Flipkart.

## Features
- Add, cancel, and update orders
- Search orders using Order ID
- Sort orders by price
- Efficient data handling using STL

## Concepts Used
- Object-Oriented Programming
- Vectors and Hash Maps
- Sorting algorithms

## How to Run
1. Compile using g++ main.cpp
2. Run the executable
